- The **Edit** dialog for the title and description of a GitHub or GitLab
  issue, or of a GitHub, GitLab or Bitbucket pull request, keeps your
  draft while its save is running. Save is held on that item until the
  save finishes; if you reopen the dialog on it before editing another
  item, the draft is still there, and so is the text of a save that
  failed while the dialog was closed.
