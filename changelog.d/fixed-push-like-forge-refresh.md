- New CI runs show up moments after you push, publish a repository or release,
  run a workflow, push a conflict resolution, or create, merge, reopen or update
  a pull request. When you push to a pull request's branch, create or reopen it,
  push its conflict resolution or update its branch, its checks and the list's
  CI badges catch up too. Deleting a branch on the remote drops the pull request
  GitHub closes with it from the open list.
