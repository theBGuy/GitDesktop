- **Submodule changes you can read.** A changed submodule is tagged in the Changes list with
  what changed (commit changed, modified files, untracked files), and selecting it lists the
  commits between the recorded and checked-out commit and the uncommitted files inside.
  **Open submodule** opens it as its own repository, and so does a double-click on the row.
  **Discard all** and **Stash all** say when a submodule's own commits and files will stay
  in place.
