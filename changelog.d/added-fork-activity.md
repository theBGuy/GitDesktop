- **Fork activity card on Insights.** See a repository's recently active direct
  forks (up to ten, most recent first), each with its latest activity, stars, and a
  link to it on the forge, plus the total fork count and a link to the full list. It
  works on GitHub, GitLab, and Bitbucket, and on GitHub a per-fork **Compare**
  fetches ahead/behind counts, showing which forks carry commits yours doesn't.
