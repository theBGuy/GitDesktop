- **Double-click a changed file to open it.** In the Changes list, a double-click opens the
  file in your external editor, or in its default program when no editor is set, and the
  command palette's **Open file in external editor** does the same for the file you're
  viewing. A file deleted from your working tree has nothing to open, so you get a short
  note instead. A double-click on a submodule opens it as its own repository.
