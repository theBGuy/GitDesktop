- **Images in comments.** Paste a screenshot, or pick files with the
  formatting toolbar's **Attach image** button, in GitHub and GitLab issue
  and pull request comments and in new pull request descriptions. PNG, JPEG,
  GIF and WebP images up to 10 MB and 40 megapixels each, 10 per draft, show
  as chips under the editor and in place in Preview, and nothing uploads
  until you post. If GitHub takes a comment but an image fails to upload,
  the comment is posted and the image stays attached for a follow-up. Images
  need GitHub CLI 2.99 or newer on GitHub.com or GitHub Enterprise Cloud
  with write access to the repository, or GitLab CLI 1.91 or newer;
  Bitbucket has no image attachments. With some GitHub CLI sign-in types,
  attaching needs GitHub CLI 2.103.2 or newer, and the app says so
  when you post.
