- **Clean up branches filters.** Narrow the list to branches merged into the
  default branch, branches whose pull request was closed without merging, idle
  branches, or any mix, with every reason that applies shown on each row.
  Branches checked out in another worktree can join the list too: acting on one
  removes its worktree first, and the confirmation names how many worktrees and
  branches it removes. The dialog opens on Archive with every filter on.
