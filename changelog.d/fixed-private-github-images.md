- Images attached on GitHub.com or GitHub Enterprise Cloud (GitHub's
  `user-attachments` links) in issue and pull request descriptions, comments,
  review threads, discussions and release notes now show in the app, and in
  most issue and pull request Previews while you write, for private
  repositories too. They load through your GitHub CLI sign-in. An image
  that can't load shows a short reason and, unless it is itself a link, an
  **Open on GitHub** link.
