- **Hide whitespace changes.** A view-options gear in the diff toolbar hides
  changes that only touch spaces, tabs or line endings in every local diff: the
  working tree, commit details, file history, branch compare, stashes and agent
  session changes. It stays on until you turn it off, and with a diff on screen
  *Show or hide whitespace changes* in the command palette flips it too. While
  it is on, the Changes diff turns off hunk and line staging and offers **Show
  whitespace** to bring it back, and a file whose only changes are whitespace
  says so.
