- **Git hooks** keep up with a hook that changes on disk while it's open: an
  unedited script reloads by itself, an edited one keeps your edit with a
  **Reload** option, and **Save** waits until a newly selected hook's script has
  loaded. **Save**, **Disable** and **Enable** stop with a notice when the
  terminal push guard was added or removed since the list loaded, and a hook
  whose script can't be read when you select it says why and offers **Retry**.
