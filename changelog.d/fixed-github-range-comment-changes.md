- On a GitHub pull request's Files tab, a comment range dragged across a gap
  between two blocks of the diff (expanded or not) keeps your text in the
  composer while **Add single comment** and **Start a review** (**Add to review**
  once a review is in progress) stay disabled and say why: "Some lines in this
  range aren't in the pull request's diff for this file." Narrow the range until
  every line of it is in the diff, context lines included, and the comment can
  post or join your review.
