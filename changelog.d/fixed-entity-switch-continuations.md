- When a release started from a tag's own page, a promotion, an edit, a delete,
  a reset, or a cherry-pick finishes after you've moved on to another tag, pull
  request, issue, discussion, branch, or commit, the dialog you opened there
  stays open and you stay where you are. A tag delete, reset, cherry-pick, or
  branch delete that finishes after you switch repositories leaves the new
  repository's dialogs and selection alone. Saving a release edit, a task, a
  review trim, a branch rename, or a branch or tag from a commit closes only the
  editor it came from, so a dialog you reopened meanwhile, or the next task you
  started typing, stays as it is.
