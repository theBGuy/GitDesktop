- When a release started from a tag's own page, a promotion, an edit, a delete,
  a reset, or a cherry-pick finishes after you've moved on to another tag, pull
  request, issue, discussion, branch, or commit, the dialog you opened there
  stays open and you stay where you are. A release you're drafting for an
  existing tag keeps its title and notes when you switch away from the app and
  back. Switching repositories closes the New discussion dialog, so every
  discussion starts in the repository you're viewing, with that repository's
  categories. While a new pull request, issue, branch, or release is being
  created, or a branch rename, squash, or repository publish is running,
  Generate waits for it to finish, so the draft you submitted stays as sent.
