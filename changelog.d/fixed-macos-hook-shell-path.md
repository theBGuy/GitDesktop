- **Git hooks find your tools on macOS and Linux.** Commits, pushes and the
  other git operations GitDesktop runs now see your login shell's PATH, so
  hooks that call node, npx, or pre-commit work when GitDesktop is launched
  from Finder, the Dock, or a Linux desktop launcher, and keep working after
  an in-app update relaunch. The Hooks dialog's install commands resolve the
  same way.
