- On macOS and Linux, fetches, pulls and pushes to GitHub or GitLab over HTTPS
  start sooner when `gh` or `glab` isn't installed: GitDesktop remembers that
  your login shell couldn't find it instead of asking again each time. If you
  later install one somewhere only your shell's startup files add to your PATH,
  use **Re-check** under **Settings → About** (or restart) so GitDesktop looks
  again.
