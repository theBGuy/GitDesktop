- **Start merges with the head branch set to be deleted.** A new **After
  merging** option in your personal *Branch rules* ticks **Delete … on the
  remote after merging** each time you open the merge dialog in that
  repository. You can still untick it for any merge, and it doesn't tick it
  for a pull request from a fork, the default branch, a promotion branch, or
  a branch a rule blocks from deletion.
