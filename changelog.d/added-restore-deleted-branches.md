- **Restore deleted branches.** Deleting a branch leaves a notice that names
  the commit it pointed at and offers **Restore**, which re-creates the branch
  there without checking it out, with its Keep local mark if it had one.
  Clean up branches offers **Restore all** for a batch of several, and
  Recover lost work lists your recent deletes under **Deleted branches**, so a
  branch can still be restored after the notice is gone.
