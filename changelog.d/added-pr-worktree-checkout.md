- **Check out a pull or merge request into its own worktree.** On GitHub,
  GitLab and Bitbucket, Checkout switches to the request's branch. The caret
  beside it offers "Check out in a worktree…", so you can review it without
  touching your current branch or uncommitted files, and switch to it in one
  step from the success message. The suggested folder sits inside the
  repository and is kept out of `git status`, an existing worktree can be
  updated to the request's latest changes, and a reset that would discard
  commits lists them and asks first.
