- **Check out a pull request into its own worktree.** On a GitHub pull
  request, the caret beside Checkout offers "Check out in a worktree…", so you
  can review it without touching your current branch or uncommitted files, and
  switch to it in one step from the success message. The
  folder is suggested for you, an existing one can be updated to the pull
  request, and a reset that would discard commits lists them and asks first.
  Needs GitHub CLI 2.98 or newer.
