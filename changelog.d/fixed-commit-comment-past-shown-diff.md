- A commit comment on a line the diff isn't drawing stays in the commit's comment
  list, with a note naming each control that brings it inline, in order: **Raw** while
  a Markdown file shows its **Preview**, **Show diff anyway** on a file shown as a
  placeholder, and **Show full diff** past the shown part of a long diff. This works
  in History and in a pull request's **Commits** tab.
